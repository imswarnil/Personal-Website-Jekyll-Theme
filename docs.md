Everything you can see on this site — thirteen content collections, the resume,
the tag index, the search — comes out of the box, and almost all of it is
configured rather than coded.

In a hurry? Clone it, run `npm run setup`, answer the form, push to a repo named
`username.github.io`. The rest is detail you only need when you want something
specific.
