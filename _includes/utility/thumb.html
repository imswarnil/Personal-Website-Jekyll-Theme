{%- comment -%} A cover, drawn rather than photographed. Used wherever a card, a list or a share image needs a picture and the entry did not provide one (`image:` / `cover:`). Nothing is fetched and nothing is built: this is an inline SVG made out of the entry's own front matter. WHAT DECIDES WHAT colour the entry's COLLECTION — the same hue its chips and rules use, derived from the one site accent pattern a hash of the title, so the same entry always gets the same art and two cards side by side never match text the collection's singular as a kicker, the title (wrapped in a , because SVG cannot wrap), and one line of whatever meta the entry happens to have The file-based twin of this is tools/thumbs.mjs (`npm run thumbs`), which draws the same picture as a real .svg for the cases that need a URL — a social card, a collection's fallback `image:`.
