--- layout: default --- {%- comment -%} ONE single-entry layout for every collection, composed from parts. What a collection's entry page looks like is DATA, not a template: each collection's `single:` block in _config.yml names the parts to stack, in order, and the widgets to put beside them — collections: portfolio: single: lead: portfolio # _includes/leads/portfolio.html parts: [breadcrumbs, head, lead, prose, tags, share, ask, comments, author, nav] widgets: [details, toc, collection, cta] sidebar: true Every name is a file: `parts` are _includes/single/.html, `widgets` are _includes/widgets/.html, the lead is _includes/leads/.html. Adding a part means adding a file and naming it — nothing here changes. A single entry can override any of the three in its own front matter. {%- endcomment -%} {%- assign coll = site.collections | where: "label", page.collection | first -%} {%- assign single = coll.single | default: site.layout.single -%} {%- assign parts = page.parts | default: single.parts | default: site.layout.single.parts -%} {%- assign has_sidebar = true -%} {%- if site.layout.sidebar == false %}{% assign has_sidebar = false %}{% endif -%} {%- if single.sidebar == false %}{% assign has_sidebar = false %}{% endif -%} {%- if page.sidebar == false %}{% assign has_sidebar = false %}{% endif -%} {%- if page.sidebar == true %}{% assign has_sidebar = true %}{% endif -%} {%- assign is_reel = false -%} {%- if page.orientation == "portrait" or page.reel %}{% assign is_reel = true %}{% endif -%} {%- if is_reel %}{% assign has_sidebar = false %}{% endif -%}
